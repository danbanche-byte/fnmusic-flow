# FnMusic Flow · 常见问题与 AI 排障指南

> 遇到问题不必干等回复：应用自带一组**诊断接口**，把它们的输出连同现象描述交给 AI 助手
> （ZCode / Claude / ChatGPT / Cursor 等均可），大多数问题几分钟就能定位。本帖整理三类
> 高频问题的自查步骤与**可直接复制的 AI 提示词**。

---

## 〇、先学会喂信息：AI 排障的三个素材

让 AI 一次贴齐三类信息，效率最高：

1. **现象描述**：你在哪个页面、点了什么、看到了什么（截图更好）；
2. **诊断数据**：浏览器直接打开下面的地址（`NAS_IP` 换成你的 NAS 局域网 IP），把 JSON 输出全文复制：

| 地址 | 用途 |
|---|---|
| `http://NAS_IP:8002/health` | 应用整体健康（worker/音源/任务统计） |
| `http://NAS_IP:8002/api/fnos/probe` | 飞牛账号绑定状态 |
| `http://NAS_IP:8002/api/fnos/candidates` | 本机可绑定的飞牛账号列表 |
| `http://NAS_IP:8002/api/sources` | 已导入音源及各自健康状态 |
| `http://NAS_IP:8002/api/tasks?limit=10` | 最近 10 个下载任务（含失败原因） |
| `http://NAS_IP:8002/api/tasks/summary` | 任务失败原因汇总 |
| `http://NAS_IP:8002/api/accounts` | 网易云/QQ 音乐连接状态 |
| 音源管理 → 某音源 →「日志」 | 单个音源脚本内部的运行日志 |

3. **环境信息**：fnOS 版本、是桌面图标打开还是浏览器直连、应用版本。

**⚠️ 安全提醒**：贴给 AI 之前，把输出里的 **token、Cookie、密码打码**（替换成 `***`）。
诊断只需要字段结构和状态值，不需要真实凭据。更不要把凭据贴给来路不明的在线服务。

**提示词模板**（复制后填空）：

```
我在飞牛 NAS 上使用 FnMusic Flow 应用（v1.3.3，通过 fnOS 桌面图标打开）。
遇到的问题：<一句话描述现象>

诊断输出（已脱敏）：
- /api/fnos/probe：<粘贴>
- /api/sources：<粘贴>
- /api/tasks?limit=10：<粘贴>

请：1) 列出最可能的 2-3 个原因；2) 给出每条原因的验证方法（命令或页面操作）；
3) 给出对应解决步骤。
```

## 一、找不到飞牛音乐的账号 / 绑定失败

**典型现象**：提示「未检测到有效凭据」、账号候选列表为空、自动绑定失败、或者绑到了家里其他人的账号。

**人工自查（按顺序）**：

1. **是否登录过飞牛音乐**？应用识别账号靠的是飞牛音乐本机的登录会话——先在飞牛音乐（网页或 APP）用你自己的账号登录一次，然后回应用「飞牛同步 → 检查连接」；
2. 打开 `http://NAS_IP:8002/api/fnos/candidates` 看有没有候选账号；
3. **多账号家庭 NAS**：在「飞牛同步」面板的账号候选里点「绑定」你自己的，应用会记住选择（账号锁），之后自动恢复也只恢复这个账号；
4. 候选里你的账号显示「无写权限」：到飞牛音乐管理设置里，把该账号的**共享库访问权限**设为「全部」，否则歌单能建但加不进歌；
5. 绑定成功但过几天又失效：正常现象（你在飞牛音乐侧重新登录会顶掉旧会话），应用每 2 分钟自动恢复，无需手动处理。

**AI 提示词示例**：

```
FnMusic Flow 无法绑定飞牛音乐账号。
- 现象：首次安装，等了 5 分钟 /api/fnos/probe 仍是 {"status":"token_missing"}
- /api/fnos/candidates：{"items":[],"locked_account":""}
- 我已确认在飞牛音乐 APP 登录过我的账号
请分析原因并给步骤。
```
（候选为空 = 飞牛音乐侧没有登录会话 → 答案大概率是「在飞牛音乐网页版登录一次再刷新」。）

## 二、无法登录音乐平台（网易云 / QQ 音乐）

**典型现象**：账号连接显示「未连接」「已过期」；搜索、日推报需要登录或 401。

**人工自查**：

1. 「账号连接」弹层里重新保存 Cookie——网易云在网页版登录后复制 Cookie 粘贴，QQ 音乐用微信/QQ 扫码；
2. **Cookie 会过期**（平台侧安全策略），过期后重新获取一次即可，应用里的旧值直接覆盖；
3. QQ 音乐部分接口需要扫码登录建立会话，不要只用 Cookie；
4. 平台风控：短时间内大量搜索/下载可能触发临时限流，歇一会儿再试。

**AI 提示词示例**：

```
FnMusic Flow 的网易云账号状态：
- /api/accounts：<粘贴>
- 现象：昨天还能搜索，今天全部报 401
请判断是 Cookie 过期还是其他原因，并给出重新配置的步骤。
```

## 三、落雪（lx-music）音源：兼容性 / 导入失败 / 下载失败

**支持哪些格式**（实测）：

| 格式 | 导入方式 |
|---|---|
| lx-music 自定义源脚本（社区分享的主流 `.js`） | 音源管理 → 导入 JS 文件 / 粘贴脚本直链 |
| 带 API_URL 声明的私有 REST 音源 JS | 同上，自动识别 |
| LX Server / API 音源服务 | 音源管理 → 链接导入，粘贴服务地址 |

**按现象对号入座**：

| 现象 | 原因与解决 |
|---|---|
| 导入报「未识别的音源格式」 | 脚本既不是标准 lx-music 自定义源也没有 API_URL——换标准格式脚本，或改用音源服务地址导入 |
| 导入成功但状态「超时/拒绝/异常」 | 音源管理里点「测试」重试；仍不行点「日志」看脚本内部报错；换源 |
| 任务失败「所有API均失败」 | 该源的上游接口临时故障，换一个源（多导几个源会自动故障切换） |
| 任务失败含「试听/invalid_audio」 | 音源返回了试听片段，应用自动拦截属正常保护，换歌/换源 |
| 任务失败「尚未配置可用音源」 | 还没导入音源，或所有源被停用 |
| 下载的文件是 `.mp3` 而请求的无损 | 该源对这首歌没有无损，应用自动降级——换源或接受音质 |

**AI 提示词示例**：

```
FnMusic Flow 下载任务失败。
- /api/sources：<粘贴>（我有 2 个音源，状态分别是…）
- /api/tasks?limit=10：<粘贴>（失败任务的 error 字段如下…）
- 音源「XXX」的日志：<粘贴>
请判断是音源失效、歌曲无资源还是配置问题，并给出下一步。
```

## 四、推送问题速查

| 现象 | 解决 |
|---|---|
| 推送停在「部分完成」 | 少数歌音源拿不到；点「重新推送」增量补试，已入单的歌不受影响 |
| 推送进度不动 | 看「飞牛推送」面板的阶段：匹配曲库（大歌单要几分钟）→ 下载缺失歌曲 → 等待飞牛索引（飞牛自身扫描有间隔，耐心等或手动触发曲库扫描） |
| 歌单推到了别人的账号 | 见第一节第 3 条（账号锁） |

## 五、让 AI 帮上忙的几个技巧

1. **一次贴齐**，别挤牙膏：现象 + 相关接口输出 + 版本，AI 少猜一半；
2. **要求 AI 先给「可能原因清单」再给验证步骤**，逐步排除而不是直接信第一个答案；
3. **让 AI 生成命令你来跑**：比如「给我一条 curl 命令查看任务失败原因」——NAS 的 SSH、Docker 命令 AI 都很熟；
4. **保存对话**：同类问题复发时把上次的诊断结论一起贴上，AI 能秒判断是不是同一个坑；
5. **脱敏纪律**：token/Cookie/密码一律打码，诊断 JSON 的结构就够 AI 分析了。
