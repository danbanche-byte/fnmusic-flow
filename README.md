# FnMusic Flow（社区版）

双平台（网易云 / QQ 音乐）歌单搜索、批量下载、飞牛音乐推送与个性化推荐，跑在飞牛 fnOS 的 Docker 里。

> **⚠️ 本应用不内置任何音源。** 下载能力依赖你自行导入的音源脚本（lx-music 自定义源 JS 或音源服务地址），安装后在「音源管理」导入即可。应用也不提供、不分发任何歌曲资源，仅供学习交流与个人本地音乐库管理。

## 功能

- **歌单广场 / 为我推荐**：双平台公开歌单浏览，口味画像驱动（`taste-profile.json`，可让 AI 按模板生成）的每日推荐池
- **歌单下载**：解析歌单链接 → 并发下载（默认 3）→ 写标签 + 内嵌封面 → 自动归档进正式曲库，支持断点续传、试听片段拦截
- **下载管理**：暂停 / 恢复 / 取消 / 删除 / 批量操作，实时进度与速度，失败自动退避重试
- **飞牛音乐推送**：歌单推送到飞牛音乐（保留封面、名称、顺序），点击立即返回、进度实时可见；收藏自动入库、日推自动同步
- **飞牛账号零配置绑定**：自动识别本机飞牛音乐登录账号，多账号可点选（账号锁），凭据失效自动恢复
- **音源管理**：文件 / 链接导入、启停、优先级排序、单独测试、运行日志，多源自动故障切换

## 安装

### 方式 A：fnOS 应用包（推荐）

从 [Releases](../../releases) 下载 `.fpk`，在 fnOS 应用中心手动安装，按向导填写音乐库路径。数据目录：`/var/apps/fnmusic-flow-community/shares/fnmusic-flow-community/data/`（升级重装数据保留，备份此目录即可整体迁移）。

### 方式 B：Docker 自部署（进阶）

```bash
git clone https://github.com/<your-account>/fnmusic-flow.git
cd fnmusic-flow
MUSIC_HOST_PATH=/vol1/音乐 docker compose up -d --build
```

需要 fnOS 环境（挂载飞牛音乐 socket 与其数据库用于账号识别与推送）。容器 `158MB` 内存左右；Web 端口 `8000` **无鉴权**，仅限内网使用，勿暴露公网。

## 首次使用

1. 「账号连接」保存网易云 / QQ 音乐 Cookie；
2. 「音源管理」导入音源（上传 `.js` 或粘贴脚本直链；不导入则下载任务会明确报错）；
3. 「飞牛同步」确认账号绑定（一般自动完成）。

## 下载与音质规则（简版）

- 优先级：单曲 > 歌单 > 日推；并发可调；曲库已有自动去重复用
- 音源按管理列表顺序尝试，失败自动退避重试，全部失败转「下载失败」可批量重试
- 音质默认请求 `hires`，源没有时按 `master → atmos_plus → atmos → hires → flac24bit → flac → 320k → 128k` 自动降级；无损落 `.flac`、有损落 `.mp3`
- 日推缓存存于音乐库 `fn_recommend_cache/`，默认 3 天删除；**收藏才会转正**到正式曲库

详细规则与排错见 [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md)（含诊断接口清单与 AI 排障提示词模板）。

## 飞牛账号说明

应用通过**只读**挂载飞牛音乐数据库识别本机登录账号，绑定后具备该账号的推送能力；你在飞牛音乐侧重新登录会顶掉旧会话，应用每 2 分钟自动恢复。多账号 NAS 可在「飞牛同步」面板点选绑定（账号锁）。
